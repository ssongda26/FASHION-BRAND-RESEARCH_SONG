+ 새 브랜드 조사 요청 (목업 — 아직 자동조사로 연결되지 않음)

▾
링크를 입력하고 조사할 카테고리를 선택한 뒤 "조사 요청 추가"를 누르면 아래 대기 목록에 기록됩니다. 실제 조사는 이 목록과 함께 채팅창에 같은 링크를 보내주셔야 진행되며, 조사가 끝나면 이 대시보드(가격 데이터 + 포지셔닝 맵)에 자동으로 반영됩니다.

☁ 데이터 게시 (관리자용)

▾
새로 조사된 데이터 JSON을 아래에 붙여넣고 "게시"를 누르면, 이 링크를 가진 모든 사람에게 새로고침만으로 반영됩니다.

브랜드별 상세 보기

왼쪽에서 브랜드를 검색·선택하면 해당 브랜드의 복종별 가격 데이터가 오른쪽에 표시됩니다. "전체 보기"를 선택하면 모든 브랜드를 한 표에서 정렬·필터할 수 있습니다.

복종별 평균가 비교

카테고리를 선택하면 해당 복종의 브랜드별 최저~최고가 범위를 평균가 높은 순으로 보여줍니다. 선택한 브랜드는 파란색, 나머지는 회색으로 표시됩니다.

브랜드 포지셔닝 맵

가로축: LOVELY(여성적·로맨틱) ↔ HIP(스트릿·엣지)  |  세로축: 평균 판매가 기준 PRICE LOW ↔ HIGH  |  위 "브랜드별 상세 보기"에서 고른 브랜드가 파란색으로 강조됩니다
가로축(스타일) 점수는 브랜드 룩·상품명 기반 정성 평가이며, 세로축(가격)은 조사된 전 카테고리 평균가의 산술평균입니다. 가격 데이터가 없는 브랜드(길라아카이브·스컬프터페이지·카시코)는 표시에서 제외되며, 신규 브랜드는 기본값(중앙)으로 표시되므로 조사 후 스타일 점수를 보정해야 합니다.

주요 인사이트

    이 대시보드는 브랜드 사이트 링크를 새로 받을 때마다 DATA 배열(가격)과 BRAND_STYLE 배열(포지셔닝 점수)에 항목을 추가하는 방식으로 계속 업데이트됩니다.
    "전체" 복종으로 표시된 브랜드(길라아카이브, 스컬프터페이지, 카시코)는 사이트 접속 제한/JS 렌더링 문제로 가격 데이터를 수집하지 못해 재조사가 필요합니다.
    "TOP(통합)" / "BOTTOM(통합)"은 해당 브랜드가 니트·티셔츠·블라우스 또는 스커트·팬츠를 하나의 카테고리로 통합 운영해 세부 분리가 불가했던 경우입니다.
